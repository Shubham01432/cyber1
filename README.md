🔐 AI-SOC-Triage-Analyzer

📌 Project Overview

This project is an AI-powered Security Operations Center (SOC) triage system designed to analyze structured cybersecurity alerts in JSON format and generate professional incident analysis reports.

The system follows a real-world SOC workflow including input validation, threat classification, risk scoring, MITRE ATT&CK mapping, and response recommendations.

---

🎯 Objectives

- Automate SOC Tier 1 alert triage
- Reduce manual analysis effort
- Provide consistent and structured security reports
- Simulate real-world SOC analyst workflow

---

⚙️ Features

- ✅ JSON alert validation
- ✅ Threat classification (Brute Force, Scanning, Malware, etc.)
- ✅ Risk scoring (0–100) with logic-based calculation
- ✅ MITRE ATT&CK mapping
- ✅ SOC analyst recommended actions
- ✅ Escalation decision logic
- ✅ Executive-level summary generation

---

🧠 Technologies Used

- AI-based analysis model
- JSON data processing
- Cybersecurity frameworks (SOC workflows, MITRE ATT&CK)

🔍 How It Works

1. Input alert data in JSON format
2. System validates required fields
3. Classifies threat type
4. Calculates risk score based on defined logic
5. Maps activity to MITRE ATT&CK
6. Generates response recommendations
7. Outputs structured SOC report
